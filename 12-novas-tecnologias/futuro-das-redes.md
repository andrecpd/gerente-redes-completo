# Futuro das Redes

Tendências importantes:
- Automação e APIs
- Infrastructure as Code
- NetDevOps
- Segment Routing
- IPv6
- SD-WAN e SASE
- Observabilidade
- Cloud networking
- Redes privadas 4G/5G
- Telemetria e análise orientada a dados

A evolução é sair de uma operação manual e reativa para uma operação automatizada, versionada e orientada por indicadores.
