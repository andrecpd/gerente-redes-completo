# Metodologias de Gestão Aplicadas a Redes

Esta pasta reúne metodologias utilizadas para organizar projetos, operação e mudanças em ambientes de redes e infraestrutura.

## Conteúdos

1. [Gestão de Mudanças](gestao-mudancas.md)
2. [ITIL aplicado a Redes](itil.md)
3. [Kanban](kanban.md)
4. [Scrum aplicado a Projetos de Redes](scrum.md)

## Como utilizar

Cada metodologia atende a uma necessidade diferente:

| Metodologia | Uso principal |
|---|---|
| ITIL | Operação, incidentes, problemas e SLA |
| Gestão de Mudanças | Alterações controladas em produção |
| Kanban | Fluxo contínuo e acompanhamento de tarefas |
| Scrum | Projetos com entregas incrementais |

## Visão Gerencial

```text
Demanda
   ↓
Prioridade
   ↓
Planejamento
   ↓
Execução
   ↓
Validação
   ↓
Indicadores
   ↓
Melhoria contínua
```

O objetivo não é aplicar uma metodologia de forma rígida, mas utilizar as práticas que aumentem organização, previsibilidade, rastreabilidade e qualidade das entregas.
