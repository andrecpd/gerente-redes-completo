# Kanban

Kanban permite visualizar o fluxo de trabalho, identificar gargalos e controlar a quantidade de atividades em andamento.

## Fluxo sugerido

```text
BACKLOG → PLANEJADO → EM ANDAMENTO → VALIDAÇÃO → CONCLUÍDO
```

## Uso em Redes

Pode ser utilizado para:

- Incidentes
- Capacity Planning
- Expansão FTTH
- Mudanças
- Projetos de backbone
- Documentação
- Automação
- Atividades de campo
- Cloud

## Organização das tarefas

Cada atividade pode possuir:

- Responsável
- Prioridade
- Área
- Prazo
- Status
- Dependências

## WIP — Work in Progress

Limitar tarefas simultâneas ajuda a:

- Reduzir atrasos
- Evitar excesso de trabalho aberto
- Melhorar foco
- Identificar gargalos

## Indicadores

- Lead Time
- Cycle Time
- Backlog
- Tarefas bloqueadas
- Entregas concluídas

## Resposta para entrevista

> Eu utilizo Kanban para dar visibilidade às atividades, priorizar demandas e acompanhar gargalos. Em redes, ele funciona bem para incidentes, projetos, expansão, documentação e automação. Também limito atividades em andamento para evitar excesso de tarefas simultâneas.
