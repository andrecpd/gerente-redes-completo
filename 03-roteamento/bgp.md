# BGP para ISP

BGP é fundamental para conectividade externa, política de rotas, multihoming, trânsito e peering.

## Pontos de estudo
- ASN
- eBGP/iBGP
- Local Preference
- MED
- AS Path
- Communities
- Prefix filtering
- Route-maps/policies
- Max-prefix
- RPKI
- Redundância

## Visão gerencial
Uma política BGP deve equilibrar disponibilidade, custo de trânsito, desempenho e controle operacional.
