# Perguntas para a Diretoria

- Qual é o principal desafio atual da rede?
- Qual crescimento de clientes é esperado?
- Quais regiões são prioridade?
- Quais KPIs a diretoria acompanha hoje?
- Onde estão os maiores riscos de capacidade?
- Como está estruturado o NOC?
- Quais decisões esta posição poderá tomar com autonomia?
- Existe orçamento planejado para expansão?
- Quais fornecedores são críticos?
- O que seria sucesso nos primeiros seis meses?
