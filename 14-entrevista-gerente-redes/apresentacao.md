# Apresentação para Entrevista

Sou profissional de Redes e Telecomunicações com experiência em projeto, implantação, operação, troubleshooting, expansão e gestão de infraestrutura.

Minha base técnica inclui BGP, OSPF, MPLS, Segment Routing, GPON/XGPON/XGS-PON, DWDM, FTTH, SD-WAN, Data Center, segurança, AWS e Azure.

Hoje busco unir essa base técnica a uma visão gerencial: pessoas, processos, SLA, capacidade, custos, fornecedores, risco e resultado.

Também venho incorporando automação, Terraform, Ansible, GitHub Actions e práticas NetDevOps para tornar a operação mais padronizada e escalável.
