## Definition of Done

Uma Issue pode ir para **CONCLUÍDO** quando:

- [ ] O conceito foi revisado
- [ ] Existe exemplo prático
- [ ] A visão de engenheiro está documentada
- [ ] A visão de gerente está documentada
- [ ] Existe pelo menos um KPI relacionado
- [ ] A resposta de entrevista está preparada
- [ ] O conteúdo foi revisado no repositório
